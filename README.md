先把结论放桌上：

**Images 2.0 解决「能画」。Images 2.5 解决「能改、能迭代、能量产」。**

2026 年 9 月 8 日，OpenAI 上线 ChatGPT Images 2.5：更锐、更好改、相对 2.0 **延迟最多约降 50%**。同步落地四个真正好用的东西——**Sketch（手机草图）**、**Templates**、**图上留言改**、**Share a prompt**。API 双轨：**Flare** 跑量，**Sunburst** 收口。

额度官方写明**不变**。更快 ≠ 无限出图。红利在试错轮次，不在玄学咒语。

## 30 秒搞懂：2.5 vs 2.0，Flare · Sunburst

别被标题党揉成一团。四月的 **Images 2.0 / gpt-image-2**，和九月的 **Images 2.5 / GPT-Image-2.5**，不是一回事。

| 名字 | 怎么记 |
| --- | --- |
| Images 2.0（2026-04） | 上一代「能画」主力 |
| Images 2.5（2026-09-08） | 更快 + 更好改 + Sketch / Templates / 留言改 |
| **Flare** | API 速度向，日更与批量默认选它 |
| **Sunburst** | API 精度向，终稿与难 prompt 再上它 |

> **四月叫 2.0，九月叫 2.5；产品侧叫 Images，API 侧叫 Flare / Sunburst。**

---

## 怎么打开（最短路径）

三条够用：

1. **对话直出**：说「用 Images 2.5 生成一张……」，或侧边栏 **Images → Create Image**。
2. **上传再改**：丢产品图 / 自拍，一次只改 1–3 个变量。
3. **手机 Sketch**：输入框 `@` → 选 **Sketch** → 先画再写描述。

**Work 模式**：生成和编辑有，**Templates 暂未进 Work**，也没有 Snake 彩蛋。模板流水线请回普通 Images 面板。

短视频 / 小红书竖图：编辑器里锁 **Aspect ratio**，或提示词写死 `9:16` / `3:4` / `1:1`，别生成后再硬裁。

Images 2.5 覆盖 **Web / 手机 / 桌面 / Codex**；Codex 里同样可生成与编辑图像。Plus / Pro / Business 仍可开 **Images with thinking**（先想再画），与 2.5 不互斥。

复杂请求仍可能要等——「最多约 50% 更低」不是「永远秒出」。

## 核心玩法

每个玩法同一套路：**配图 + 怎么做 + 可抄提示词**。图对题，不塞新闻卡。

### 玩法 01｜Sketch：画三笔，胜过写八百字

手机专属。官方逻辑很实在——有时候解释想法最清楚的方式，就是画出来。

![手机 ChatGPT 打开 @Sketch 手绘](https://upload.maynor1024.live/file/1788915116606_sketch-demo-thumb-2.jpg)

*输入框打 `@` 选 Sketch：先画轮廓，再补风格。*

![Sketch 成片演示缩略](https://upload.maynor1024.live/file/1788915117384_07-sketch-demo-thumb.jpg)

*草图 → 成片的产品叙事：构图交给手，美学交给模型。*

![用 @Sketch 给模型视觉参考](https://upload.maynor1024.live/file/1788915136162_russell-sketch-thumb.jpg)

*别只靠文字玄学——草图就是空间 brief。英文圈也在刷同一套叙事。*

**怎么做**

1. 打开 ChatGPT App  
2. `@` → **Sketch**  
3. 画主轮廓（有颜色、橡皮、撤销）  
4. 打勾，再写主体 / 材质 / 光线 / 比例  
5. 发送

**可抄提示词**

```text
根据我的草图生成成片：
- 严格遵守草图的构图与透视
- 主体：【产品 / 人物 / 室内】
- 风格：【写实摄影 / 日系插画 / 3D 渲染】
- 光影：【窗光 / 影棚柔光 / 霓虹夜景】
- 不要额外添加草图里没有的主体
- 宽高比：【9:16 / 1:1 / 16:9】
```

室内一键：

```text
把这张平面潦草布局变成室内效果图：
保留墙体分隔与家具大致位置；
风格：现代日系原木；光线：下午侧窗光；
材质：橡木地板、亚麻窗帘；镜头：24mm，无人。
```

适合：包装线框、App UI、分镜火柴人、房间布局。  
不适合：超密集小字海报（先 Templates）、法律级工程图。

### 玩法 02｜参考图换装：改衣服，别换狗

2.5 官方反复强调：**参考图主体换场换装，仍更像「同一个」**。社区拿 Photoshop 比喻，不是图层来了，是修改心理模型变了——从重抽，变成修订。

![官方样张：参考原图里的狗](https://upload.maynor1024.live/file/1788915104642_01-chatgpt-official-a.jpg)

*先锁身份，再谈创意——官方样张的「真人感」参考。*

![同一只狗穿上 STUNTMAN 战衣](https://upload.maynor1024.live/file/1788915106484_02-chatgpt-official-b.jpg)

*同构图换装：衣服合身、胸前文字可读、姿势尽量不动。*

**怎么做**

1. 上传 1–3 张清晰参考图  
2. 首句写死「身份锁定」  
3. 只改服装 / 场景 / 道具，一轮不超过 3 个变量  
4. 漂了就回退，别在烂图上继续叠

**可抄话术**

```text
身份锁定：与参考图为同一主体，五官/毛色/体态比例不变。
只改：服装→复古特技服 + 头盔，胸前清晰英文「STUNTMAN」；
场景与姿势尽量保持。
禁止：换脸、整容感、另造一个主体、过度磨皮。
```

人像把「主体」换成「同一人」，服装换成你的 brief 即可。

### 玩法 03｜Templates：同一骨架，只换标题

多数营销图是「骨架不变，文案变量」。Templates 钉死骨架，你填投放简报，而不是每次从零写 prompt。

![创作者工作台：模板与迭代](https://upload.maynor1024.live/file/1788916225428_play-rrweb3.jpg)

*从想法到成片：模板起稿、可继续 Edit——日更封面党友好。*

**怎么做**

1. **Images → Templates**  
2. 选海报 / Merch / 产品图等  
3. 追问时答清：受众、场合、情绪、必须出现的字  
4. 有上传口就塞品牌色 / 人像 / 产品图  
5. 生成后对话改，或进编辑器精修

> Templates **还没进 Work**。

**可抄补丁**

```text
用途：AI 工具课招生海报
标题：ChatGPT Images 2.5 实战营
副标题：Sketch 到成片，7 天做出可售卖视觉包
风格：高对比赛博蓝 + 黑，大标题可读
必须保留：右下角极简 logo 占位
禁止：花哨贴纸、过多装饰线
比例：3:4
```

一天 30 张封面：固定品牌色与字体描述，**只改标题变量**，再用 Share Prompt 把母版存进团队文档。

### 玩法 04｜图上留言改：改哪里，就尽量只动哪里

如果说 2.5 有一个值得刷屏的卖点，不是「首图更美 10%」，而是：

> **改你想改的，不动其他细节。**

手机全屏打开图：**Edit** 整体描述，**Select** 刷局部，**Comment** 点位置写「这里改成……」。

![中文解读：局部编辑更听话](https://upload.maynor1024.live/file/1788916234096_play-xifen-1.jpg)

*「让它改哪里，就尽量只改哪里」——打的就是旧痛点：改个 logo，脸也一起漂。*

**怎么做**

1. 点开成片 → Comment / Select  
2. 话术写清「只改标注区」  
3. 一轮最多 1–3 个变量  
4. Undo / Redo 当历史记录

**可抄话术**

```text
只改我标注的区域：
1) 把包上的 logo 换成白色极简「MAYNOR」
2) 不要改人物脸、发型、姿势、背景
3) 保持原来的光影方向和色温
```

```text
同一张图继续，不要重新构图。
只提高皮肤真实毛孔，去掉塑料感；背景虚化略加强。
```

多轮顺序：构图 → 服装道具 → 光影色彩 → 文字 logo →（可选）透明底。  
把每次编辑当成「最多 3 个变量」的预算——超了就拆下一轮。这是纪律，不是模型限制。

连续四轮修同一处还越修越脏？另开新枝，止损比硬刚值钱。

官方提醒：选区**不完全精确**，复杂结构要小步多轮。

### 玩法 05｜不可能 Prompt：汉堡 + 时钟压测

测评最容易上热的体裁：**同 prompt 左右对打**。复杂物理、可读文字、模拟时钟——老模型爱翻车的地方。

![压测样张 A：汉堡、红酒与挂钟](https://upload.maynor1024.live/file/1788916225556_play-clock-a.jpg)

*时钟数字顺序、指针、食物材质同框——典型难 prompt。*

![压测样张 B：另一构图的时钟压力测试](https://upload.maynor1024.live/file/1788916222968_play-clock-b.jpg)

*换构图再压：招牌字 + 闹钟 + 餐食，看细节是否一起稳住。*

**怎么做**

1. 锁死比例，标明模型 / 档位  
2. ChatGPT 2.5 出一张；有 API 再打 Flare / Sunburst  
3. 发内容时诚实标参数，别偷偷降档打假胜利

**可抄压测词**

```text
写实餐饮静物，木质桌面：
前景一份多层芝士汉堡（芝士拉丝可见），旁放一大杯红酒；
背景挂一只模拟挂钟，数字 1–12 正确、指针指向约 3:32；
浅景深，暖光侧打，玻璃高光真实，文字清晰无误。
禁止：数字乱序、融化成糊的指针、塑料感食物。
```

### 玩法 06｜写实到发抖：社交感人像

2.5 更吃材质与光影。别堆十个艺术家名字：写清**焦距、机位、光型、介质**，主风格只选 1 个。

![酒窖写实人像](https://upload.maynor1024.live/file/1788916223330_play-photoreal.jpg)

*皮衣纹理、酒杯高光、发丝与肤色——用光影和材质描述压「AI 塑料感」。*

**怎么做**

1. 先定场景与情绪，再写镜头  
2. 明确「保留毛孔 / 不要美颜磨皮」  
3. 需要文字就单独一轮只改字

**可抄提示词**

```text
超写实社交感人像，浅景深：
主体：长发女性，深色皮衣，手托下巴，表情克制俏皮；
场景：昏暗酒窖餐厅，背后酒架暖光；
前景：红酒杯与水杯虚化高光；
镜头：50mm，侧前方暖光 + 轻微轮廓光；
皮肤保留毛孔，禁止塑料磨皮；比例 3:4。
```

### 玩法 07｜2.0 vs 2.5：同题左右对打

别只说「更锐」。同一条难 prompt 左右贴上，读者自己站队。社区常用 GPT Image 2 High 4K vs 2.5 Sunburst High 4K——复测时写清平台与档位。

![对比左：GPT Image 2](https://upload.maynor1024.live/file/1788915107021_03-compare-image2.jpg)

*同题左：雨夜钟表店、人机协作、玻璃字——看文字与反射。*

![对比右：GPT Image 2.5 Sunburst](https://upload.maynor1024.live/file/1788915115195_04-compare-sunburst.jpg)

*同题右：细节、窗字、雨滴与猫——左右并排比写一千字参数有用。*

**怎么做**

1. 锁死 prompt、比例、参考图（如有）  
2. 左 2.0 / 右 2.5（或 Flare / Sunburst）  
3. 标题直接写：「同 prompt，你站哪边」

```text
透过雨夜橱窗看修表店：女表匠与黄铜小机器人共同修理机芯；
玻璃金字「L'ATELIER DU TEMPS」可读；店内暖台灯，室外冷色车灯虚化；
架上橘猫睡觉；电影感写实，细节锐利。
```

### 玩法 08｜Sunburst 收口 + Prompt 分享

日更别上来就烧 Sunburst。分流：

- **Flare**：构图探索、批量封面、产品默认链路  
- **Sunburst**：广告终稿、复杂文字、苛刻一致性

![Sunburst 向精修：长句 T 恤仍清晰](https://upload.maynor1024.live/file/1788916230604_play-sunburst-art.jpg)

*复杂场景 + 衣服褶皱上的长句仍可读——这种终稿感更适合 Sunburst 收口。*

手机：**Share → Prompt template → Copy link**。适合团队规范、小红书可复刻模板、给客户交「可改参数的提示词包」。分享前抠掉机密与人脸敏感信息。

**可抄分流话术**

```text
方案 A（快）：Flare 出 8 张概念，选 2 张精修 → 社媒排期
方案 B（稳）：Flare 定构图 + Sunburst 出终稿 → 详情页主视觉
方案 C（狠）：Sketch 定结构 → Templates 起稿 → Comment 三轮 → Sunburst 收口
```

## 提示词精选（少而精）

结构公式够用就行：

```text
[主体] + [动作/情绪] + [环境] + [镜头] + [光线] + [材质] + [必须保留] + [禁止] + [比例]
```

**1｜电商白底主图**

```text
白底电商主图，1:1：
产品居中，完整显示瓶身/标签；
柔光棚拍，轻微投影；
标签文字清晰无误；
不要道具堆砌，不要手模抢戏。
```

**2｜小红书竖版封面**

```text
小红书竖版封面 3:4：
大标题中文「」字号巨大、缩略图仍可读；
背景【纯色 / 生活场景虚化】；
主体约占画面 60%；
风格明亮高对比，少文字；
右下角留 10% 安全区给平台控件。
```

**3｜透明背景贴纸**

```text
生成角色贴纸，背景透明：
线条干净，描边统一；
表情：【】；
适合微信表情或 Merch 印花；
不要阴影接地，不要实底。
```

**4｜身份锁定换场景**

```text
身份锁定：与参考图为同一人，五官比例、肤色、发型、年龄感不变。
只改：服装→【】；场景→【】；表情可微调为【】。
保持：原有脸型与痣/特征点。
禁止：换脸、整容感、过度磨皮、另造一个人。
```

**5｜编辑短句（往往比长 prompt 更香）**

- 「只改……，其它像素级保持」  
- 「同一张图继续，不要重新构图」  
- 「文字改成中文『』，字距紧凑，不要错字」  
- 「去掉多余手指，修复手部结构」  
- 「logo 边缘更锐，不要发虚」

负面约束写**可验证的禁止项**，别堆一百个 `low quality`。

![材质混搭字标 Images 2.5](https://upload.maynor1024.live/file/1788916229950_play-xifen-2.jpg)

*大理石、棒球、笔触、热气球——材质写具体，比空喊「高质量」有用。*

## Flare vs Sunburst：怎么选

![Flare 速度向 vs Sunburst 精度向](https://upload.maynor1024.live/file/1788916228706_play-flare-sunburst-jp.jpg)

*想快速迭代用 Flare；要高精度收口用 Sunburst。*

| | **Flare** | **Sunburst** |
| --- | --- | --- |
| 定位 | 速度 / 综合 | 精度 / 难 prompt |
| 适合 | 批量、日更、高并发、草稿 | 广告终稿、复杂文字、角色一致性 |
| 代价 | 更快 | 生成更久 |
| 口诀 | 日更主力 | 终稿精修 |

社区提到 `xhigh` / `max` 等档——**以你账号 API 文档当时可见枚举为准**；第三方站可能先挂名后补能力。

实操：Flare 先出 4 张 → 挑一张再 Sunburst。产品默认 Flare，后台「精修」走 Sunburst，最省钱也最诚实。

## 避坑 FAQ（短）

**Q：为什么我没有 Sketch？**  
滚动发布。确认 App 已更新；Sketch 在**手机输入框 @**，网页别硬找画板。

**Q：Work 里找不到 Templates？**  
正常。官方：Templates are not yet available in Work mode。

**Q：额度会因 2.5 变多吗？**  
官方：existing image-generation limits are unchanged。

**Q：选区改完还是动到旁边？**  
选区不完全精确。改小一点、多轮、写「只改标注区」。

**Q：还能用 DALL·E GPT 吗？**  
不能，已退役。用 ChatGPT Images。

**Q：第三方显示 2.5，图质一般？**  
可能挂名或档位不同。同 prompt 对照官方 ChatGPT。

**Q：生成还是慢？**  
复杂提示、Thinking、Sunburst、高峰期都会变慢。「最多约 50%」≠「永远快一半」。


**Q：Codex 里能用吗？**  
能。官方写明覆盖 Codex；Help Center 亦说明可在 Codex 生成与编辑图像。

**Q：怎么删 Images 里的图？**  
删除**生成该图的那条对话**（Web 标题 `•••` → Delete；手机长按对话标题 → Delete）。

再钉四条：模型名别混（2.0 vs 2.5）；一次别塞 8 个互斥修改；商用人脸/商标先过授权；Work 无 Snake。
